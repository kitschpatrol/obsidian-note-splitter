# Note Splitter demo

Run `pnpm dev` from the repository root, then open this folder as an Obsidian vault and enable community plugins.

Open [[Sample note]] and run **Note Splitter: Split by delimiter** from the command palette. With the default settings, the plugin creates one note per nonempty line in the `note-splitter` folder.

Try changing the delimiter, output folder, and **Use content as title** options in the plugin settings.
